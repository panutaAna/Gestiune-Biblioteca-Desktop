Gestionarea unei biblioteci

Proiectul „Gestionarea unei biblioteci” reprezintă un prototip de aplicație desktop destinat organizării activității unei biblioteci. Acesta permite vizualizarea și căutarea cărților, adăugarea unor titluri noi, precum și gestionarea împrumuturilor și retururilor.
Proiectul include un prototip realizat în Figma, diagrame UML și o arhitectură modulară care separă interfața grafică, logica aplicației și stratul de date.
